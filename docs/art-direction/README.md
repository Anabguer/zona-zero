## Pregunta de aprobación

> **¿Queréis que Zona Zero se vea así?**

Si la respuesta es sí, la siguiente pasada ejecuta arte completo + integración + sistemas + balance + producción de una tacada.

## Principios visuales (cerrados en esta propuesta)

1. Mundo continuo ilustrado (no diagrama de nodos, no pestañas tipo app).
2. Territorio controlado = verde/luz; desconocido = niebla; hostil = rojo/óxido.
3. Edificios reconocibles (refugio, huerto, torre, taller…), no cajas con letras.
4. Solo exploradores tienen rostro; la población es masa + números.
5. Paleta tierra/hormigón/óxido — sin neón púrpura, sin dashboard admin.
6. Técnica objetivo: SVG/CSS ligeros en web (la muestra PNG define el techo artístico a alcanzar).

## Limitación honesta de la muestra

Las PNG son **mockups de dirección** (calidad ilustrada objetivo). El motor actual aún renderiza SVG procedural más simple; el lote final de assets se hará solo tras aprobación.
